# Controls

**Two-handed keyboard layout:** left hand stays on W A S D with Shift (sprint), Space (precision / shield / first-time) and Q / E (modifiers); right hand rests on the J K L I cluster (pass / through / lob / shoot) with U O M . for skill moves. Nothing needs to be reached across the board. A saved v1 keyboard layout is reset to this one automatically on first load.

Controls are mapped to the same abstract actions on every device; on-screen prompts follow the last device used. Everything is rebindable in **Settings → Controls** (conflicts are flagged, profiles can be saved).

## Attacking
| Action | Gamepad | Keyboard / mouse | Touch |
|---|---|---|---|
| Move | Left stick | WASD (left hand) | Floating left joystick |
| Ground pass (hold = power) | A | J / left click | PASS |
| Through pass | Y | K / right click | THROUGH |
| Lob / cross | X | L | LOB (double-tap = low cross) |
| Shoot (hold = power) | B | I | SHOOT (swipe up = finesse, down = chip) |
| Finesse / chip / low cross | RB+B / LB+B / LB+X | E+I / Q+I / Q+L | modifier buttons |
| First-time | LT + A/B/Y while the ball arrives | Space + action | tap as the ball arrives |
| Sprint | RT | Shift (left hand) | SPRINT |
| Precision dribble / shield | LT | Space (or Ctrl) | SHIELD |
| Skill moves (your 4 chosen) | Right stick: push up / right / down / left (roll the stick for chains) · hold LB + push for a second set of 4 | U / O / M / . (right hand), arrow keys, 1–4 · hold Q for the second set | SKILL then flick on the right pad, or 4 skill buttons |
| Run / call for pass | RB | E | RUN |
| Pause | Start | Esc / P | II |

## Defending
| Action | Gamepad | Keyboard | Touch |
|---|---|---|---|
| Switch player (nearest goal-side defender to the ball; hold a stick direction to pick that side) | B / LB | Q | SWITCH |
| Tackle (tap) / press (hold) | A | J | TACKLE |
| Slide | X | L | SLIDE |
| Jockey / contain (hold; auto goal-side positioning) | LT | Space | CONTAIN |
| Second presser | RB | E | 2ND PRESS |
| Keeper charge | Y | K | KEEPER |

## Set pieces
Aim with the stick (or the mouse), hold shoot/cross for power, rotate the right stick for curl. Free kicks: LB/RB (Q/E) move the wall. Corners: Q = outswing, E = inswing, pass = short corner. Penalties: stick aims, shoot fires, X/L chips (panenka).

## Goalkeeper (when you control the keeper)
LB/RB (Q/E) dive left/right, Y/K rush out, A/J throw, X/L kick. Keeper assist (Settings) adds automatic dives.

Low cross is Q+L (not Shift+L) because Shift is sprint; see DECISIONS.md.

**Skip:** during goal celebrations/replays, injury stoppages, and while a corner/free kick/throw-in/kick-off is being set up, press ✕ (gamepad), L1 + R1 together (Q + E on keyboard), Enter, or tap the on-screen Skip chip to jump straight to the restart.

**Skill moves like a console game:** push the right stick (fast or slow) while you have the ball. Each direction is one of your four chosen moves; hold LB (Q on keyboard) to use a second set of four. Players too unskilled for a chosen move automatically perform the best move they can do. The player card at the bottom-left shows what each direction does. Both sets are editable in Settings → Controls.
