# Controls

Football Simulator is a manager game: there is no player control. Everything is mouse / touch driven, with a few hotkeys while a match plays.

## While watching a match
| Key | Action |
|---|---|
| Space | Pause / resume (starts the match from the kick-off card) |
| Esc | Pause menu (resume, tactics, camera, leave match) |
| 1 / 2 / 3 / 4 | Playback speed 0.5× / 1× / 2× / 4× |
| F | Finish — fast-forward to half-time / full-time |
| T | Tactics & formation (opens a pausing panel; changes apply immediately) |
| S | Substitutions |

Hover a player to see their name, role, rating and condition. The bar at the bottom of the screen has the same actions as buttons, plus the stats panel.

## Managing
- **Formation**: click a formation card; the lineup is re-sorted automatically.
- **Lineup**: on the pitch editor, click one token then another (or drag) to swap two players; bench players can be swapped in the same way. *Auto-pick best XI* fills the strongest side for the formation.
- **Tactics**: pick a style preset or adjust the sliders (mentality, pressing, width, tempo, defensive line, etc.).
- **Transfers**: open the market, click a player card for details, then make an offer. Scouting reveals true ratings.

## Settings
Settings → Match: match length, playback speed, camera, player names, ticker, VAR, goal replays, auto-pause at half-time, weather / time of day / stadium, difficulty and rules.
