## Assets
There are **no bundled third-party assets**.
- Textures (grass, kits, ball, crowd seats, boards, skyline) are generated on canvas at runtime.
- Audio (crowd, whistle, kicks, UI, music) is synthesised with the Web Audio API.
- Player/stadium geometry is procedural.
- The UI font is the system font stack.

Because nothing is downloaded, no CC0/CC-BY attribution is currently required. If you add assets (Quaternius, Kenney, Poly Haven, freesound CC0…), list each file, source URL and licence here.
